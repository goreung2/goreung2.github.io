# 글쓰기 문법 가이드

`posts/*.json`의 `content` 필드에 쓸 수 있는 문법 전체 정리입니다.
기본 마크다운(GFM) + 이 블로그에서 추가한 확장 문법을 함께 씁니다.

---

## 1. 기본 마크다운

```
# 제목 1
## 제목 2
### 제목 3

**굵게**, *기울임*, ~~취소선~~

- 목록
- 목록

1. 순서 목록
2. 순서 목록

> 인용구

[링크 텍스트](https://example.com)

---   (가로줄)
```

인라인 코드는 백틱 하나, 코드블럭은 백틱 세 개로 감쌉니다.

```
`인라인 코드`

​```javascript
const x = 1;
​```
```

표(table)도 GFM 문법 그대로 됩니다.

```
| 이름 | 값 |
|---|---|
| a | 1 |
| b | 2 |
```

## 2. 이미지

### 기본
```
![대체 텍스트](../images/파일명.jpg)
```
아무 옵션 없으면 화면 폭에 맞게 반응형으로 표시됩니다.

### 크기 조절
```
![alt](url){small}
![alt](url){medium}
![alt](url){large}
![alt](url){full}
![alt](url){width=300}
```
| 옵션 | 설명 |
|---|---|
| `small` | 최대 220px |
| `medium` | 최대 420px |
| `large` | 최대 100% (기본과 동일) |
| `full` | 여백 없이 100% 꽉 채움 |
| `width=숫자` | 픽셀 단위 직접 지정 |

### 정렬 + 캡션
```
![alt](url){right caption="사진 설명"}
```
| 옵션 | 설명 |
|---|---|
| `left` | 왼쪽 정렬, 글이 오른쪽으로 흐름 |
| `right` | 오른쪽 정렬, 글이 왼쪽으로 흐름 |
| `center` | 가운데 정렬 |
| `caption="텍스트"` | 사진 아래 캡션(설명) 표시 |

옵션은 공백으로 여러 개 조합 가능: `{small right caption="설명"}`

> 이미지 파일은 `/images` 폴더에 올린 뒤 상대 경로(`../images/파일명.jpg`)로 불러옵니다.

## 3. 색깔 있는 텍스트

```
{color:gold}골드색 텍스트{/color}
{color:red}빨간 텍스트{/color}
{color:green}초록 텍스트{/color}
{color:blue}파란 텍스트{/color}
{color:#123abc}원하는 hex 색상{/color}
```

사용 가능한 이름: `gold` `green` `red` `blue` `ink` `gray` — 이 외에는 `#hex` 코드를 직접 씁니다.

## 4. 하이라이트 & 위첨자

```
==형광펜처럼 강조==
x^2^   (위첨자)
```

---

## 5. 콜아웃 박스 (강조 박스)

```
:::tip
알아두면 좋은 팁 내용
:::

:::info
참고할 정보
:::

:::warning
주의가 필요한 내용
:::

:::note
짧은 메모
:::
```
박스 안에서도 굵게/목록/이미지 등 다른 마크다운 문법을 그대로 쓸 수 있습니다.

---

## 6. 2단 컬럼 레이아웃

```
:::columns
왼쪽에 들어갈 내용
---
오른쪽에 들어갈 내용
:::
```
`---`를 기준으로 좌우가 나뉩니다. 각 컬럼 안에도 마크다운을 자유롭게 쓸 수 있습니다.
모바일 화면에서는 자동으로 위아래로 쌓입니다.

---

## 7. 버튼형 링크

```
[텍스트](https://example.com){button}
```
일반 링크처럼 밑줄 있는 텍스트가 아니라, 눌러지는 버튼 모양으로 표시됩니다.

---

## 8. 빠른 참고표

| 하고 싶은 것 | 문법 |
|---|---|
| 작은 이미지 | `![alt](url){small}` |
| 오른쪽 정렬 + 캡션 | `![alt](url){right caption="설명"}` |
| 색깔 텍스트 | `{color:gold}텍스트{/color}` |
| 형광펜 | `==텍스트==` |
| 위첨자 | `x^2^` |
| 팁 박스 | `:::tip` ... `:::` |
| 2단 컬럼 | `:::columns` ... `---` ... `:::` |
| 버튼 링크 | `[텍스트](url){button}` |
| 코드블럭 | ` ```언어 ` ... ` ``` ` (언어 라벨 자동 표시) |
